# JARVIS SCULPTURA — Android

Assistente vocale Android per SCULPTURA, progettato per Android 16 (API 36).

## Obiettivo

Interfaccia minimal futuristica con orb centrale, attivazione vocale tramite **Jarvis** o **Ferrovecchio**, risposta vocale italiana, apertura delle app, ricerca web e automazione controllata tramite Accessibility Service.

## Sicurezza

JARVIS esegue direttamente le azioni innocue. Le azioni sensibili o distruttive devono richiedere conferma dell'utente.

## Build

Il progetto viene compilato automaticamente con GitHub Actions. L'APK debug viene pubblicato come artifact della workflow `Build Android APK`.

> Progetto in sviluppo. Non è affiliato né copia asset proprietari di Iron Man/Marvel; l'interfaccia usa un HUD originale ispirato a estetiche futuristiche.
